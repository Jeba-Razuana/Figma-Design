# Figma Design

Frontpage Website Design (Figma → HTML & Tailwind CSS)

A modern, responsive frontpage website built by converting a Figma design into clean and maintainable code using HTML5 and Tailwind CSS.
This project demonstrates strong attention to design accuracy, responsiveness, and frontend best practices.

🌐 Live Demo

🔗 View Live Project:
👉 http://127.0.0.1:5500/index.html

🛠️ Technologies
HTML5 – Semantic and accessible markup
Tailwind CSS – Utility-first styling and responsive design

✨ Key Features
📱 Responsive Design – Optimized for mobile, tablet, and desktop
🎯 Pixel-Perfect UI – Closely matches the Figma design
🧩 Clean Structure – Well-organized layout sections
⚡ Lightweight & Fast – No unnecessary dependencies
🎨 Modern UI/UX – Clean typography and spacing

⚙️ Development Process
Analyzed Figma design (layout, colors, typography)
Structured layout using semantic HTML
Styled using Tailwind CSS utility classes
Implemented responsive design using breakpoints
Tested across multiple devices and browsers
